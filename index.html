The idea

A declaration is only useful if someone checks it.

Packaged products carry a set of required declarations, and those declarations are governed by legal-metrology rules. Checking them by hand, at scale, is slow and easy to get wrong. This concept explores an assistive tool: capture the label, extract the declared fields with OCR, compare them against what the rules expect, and flag the ones that are missing or inconsistent for a human to review.

This is a concept, not a shipped product.

There is no working prototype in this repository yet. The page describes the intended design and the problem it aims at.

What it would do

What it would do

Four capabilities the concept is built around.

Label capture and OCR

Read the printed declarations from a photo of the label — quantities, prices, dates and manufacturer details.

Declaration checks

Compare the extracted fields against the expected format and the requirements that apply to the product.

Flagging, not guessing

Missing or inconsistent declarations are surfaced for review instead of being silently accepted.

Batch review

A queue for working through many products, rather than checking one label at a time.
